How It Works

Browse / 6,750 Entries (5,796 Usable Mods) With Reach Ratings - awesome-claude-code-mods

Token Optimizer Bar (above the prompt)
Quality (S best to F) - how clear the conversation still is to Claude. C is 55-69; long, cluttered sessions lower it
Context % - how full Claude's working memory is. Under 50% is fine; past about 70% it starts losing earlier details
Cache (minutes) - time left to pick the conversation back up cheaply. Away longer, the next message uses more of your allowance to reload
5 hours % - share of your rolling 5-hour usage allowance used
Week % - share of your weekly allowance used. The one to watch: when it runs out you wait for the weekly reset

Clean Up / Same as /compact - shrinks the conversation into a summary and keeps going in the same session. Use when quality drops to D or context passes about 70%

Start Fresh / New Chat With Notes - saves a summary, wipes the conversation, and hands the summary to Claude with your next message. Asks for a second click. Use when switching to a different task

Keep Warm / Reset the Cache Timer - uses a tiny bit of usage. Only worth it if you are stepping away and coming back to the same conversation

Reload / Mods in an Open Session - type /reload-plugins (new sessions load them on their own)

Keep / ~/Projects/claude-mods Folder - holds Blast Radius, Secret Redactor, Agent Narrator, Prompt Coach, Lighthouse Run, Slopless; deleting it breaks them

Remove / A Mod - /plugin uninstall name@marketplace
