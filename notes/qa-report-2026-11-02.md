## Problems found, most serious first

1. **Four safety guards failed open.** In Command Guard, Voice Guard, Collision Guard and Limit Guard, closing the "are you sure?" box without picking an answer let the action go ahead. Example: a `git push --force` ran after the box was closed. **Fixed:** closing the box now counts as the safe answer (Cancel, Stop here, or Skip it). The simulation confirms the risky command and the AI-sounding email are now stopped.
2. **Session Keeper's band crashed during a handoff.** While a handoff was open, the band above the prompt failed to draw ("h is not a function"), so the handoff buttons and the cache bar disappeared. **Fixed:** a variable name clash in the drawing code.
3. **Voice Guard's `/voice` command never registered.** `/voice` is already a built-in Claude command, so the app refused it. **Fixed:** renamed to `/voiceguard` in the code, both READMEs, `mods.json`, `suite.json` and the catalog.
4. **Version numbers were out of step.** Each mod's own version file said 2.0.0 while the marketplace said 2.1.x or 2.2.0. `mods.json` also lacked the newer versions, so re-running `scaffold.py` would have rolled them back. The installs already had the right versions, so nothing was missed. **Fixed:** all three places now agree. A trial run of `scaffold.py` keeps them.
5. **Shared catalog failed the type check.** The `Part` type in `shared/catalog.ts` (and the generator in `scaffold.py` that writes it) lacked the `default` field the data uses. **Fixed.**
6. **Mission Control pointed to the wrong tool.** Its reminders always said to call `mcp__mission-control__plan`, even when the app's own task list is in use. Its counting was already right. **Fixed:** the wording now names whichever list is in use.
7. **Privacy Shield false alarm (not changed).** It blocks any shell command that mentions a file ending in `/.env` alongside a reading command, even when nothing is being read. It caught one of my test scripts. I left it alone, because loosening a privacy filter should be your decision.
