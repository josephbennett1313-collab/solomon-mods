# Design Picker

Opens by itself on design questions: live mockup cards built with design skills, with motion, and a Send to Figma step.

Part of [Solomon Mods](https://github.com/josephbennett1313-collab/solomon-mods), a free set of Claude Code mods by Joseph Bennett.

## Install

```
/plugin marketplace add josephbennett1313-collab/solomon-mods
/plugin install design-picker@solomon-mods
```

## Use

Commands: /styles.
It opens as a tab beside the chat.
Turn it, or any part of it, on or off from the Mods tab (`/mods`).

## Parts you can switch off

- `tool`: Let Claude open it before building a new interface
- `auto`: Open by itself when you ask to build a page, site or app
- `figma`: Show Send to Figma on each style
