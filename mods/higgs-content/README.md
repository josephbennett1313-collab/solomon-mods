# Higgs Content

A photo and video studio on the Higgsfield connector: describe, review the upgraded prompt and credit cost, create, and browse the gallery.

Part of [Solomon Mods](https://github.com/josephbennett1313-collab/solomon-mods), a free set of Claude Code mods by Joseph Bennett.

## Install

```
/plugin marketplace add josephbennett1313-collab/solomon-mods
/plugin install higgs-content@solomon-mods
```

## Use

Commands: /create.
It opens as a tab beside the chat.
Turn it, or any part of it, on or off from the Mods tab (`/mods`).

## Parts you can switch off

- `upgrade`: Upgrade my prompt before creating
- `quote`: Show the credit cost and wait for my yes
