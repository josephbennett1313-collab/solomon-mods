# Session Keeper

One panel above the prompt: crab that snows when the cache is cold, quality/context/cache/limit rings, token weather, chat facts, cache buttons, Auto Model with fast mode and Ultracode buttons, a hold on cold-cache messages, and a device-aware handoff.

Part of [Solomon Mods](https://github.com/josephbennett1313-collab/solomon-mods), a free set of Claude Code mods by Joseph Bennett.

## Install

```
/plugin marketplace add josephbennett1313-collab/solomon-mods
/plugin install session-keeper@solomon-mods
```

## Use

Commands: /keeper · /handoff · /keepwarm.
It shows above the prompt or acts in the background.
Turn it, or any part of it, on or off from the Mods tab (`/mods`).

## Parts you can switch off

- `bar`: The panel above the prompt (rings, token weather, facts, cache buttons)
- `fox`: Animated Claude crab (snow falls on it when the cache has gone cold)
- `suggest`: Smart button that suggests the best command right now
- `automodel`: Show Auto Model inside the panel (model, effort, fast mode and Ultracode buttons)
- `hold`: Hold my message when the cache has gone cold and show the cost first
- `handoff`: Offer a handoff when the chat gets long
- `keepwarm`: Allow keep-warm pings
