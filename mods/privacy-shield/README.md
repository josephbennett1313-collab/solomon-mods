# Privacy Shield

Masks names, emails, phones and amounts while you share your screen, keeps keys out of what Claude reads, and blocks .env and SSH key files.

Part of [Solomon Mods](https://github.com/josephbennett1313-collab/solomon-mods), a free set of Claude Code mods by Joseph Bennett.

## Install

```
/plugin marketplace add josephbennett1313-collab/solomon-mods
/plugin install privacy-shield@solomon-mods
```

## Use

Commands: /screen-share.
It shows above the prompt or acts in the background.
Turn it, or any part of it, on or off from the Mods tab (`/mods`).

## Parts you can switch off

- `screen`: Screen-share masking (/screen-share)
- `secrets`: Hide keys and tokens from Claude
- `prompt`: Catch keys pasted into a prompt
- `keyfiles`: Ask before Claude opens key files (.env and the like)
