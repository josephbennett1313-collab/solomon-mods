# Helper Desk

A Helper Desk tab with a crab card per helper agent, chat cost, helper tokens and time, a saved to-do list, and a team-size dock.

Part of [Solomon Mods](https://github.com/josephbennett1313-collab/solomon-mods), a free set of Claude Code mods by Joseph Bennett.

## Install

```
/plugin marketplace add josephbennett1313-collab/solomon-mods
/plugin install helper-desk@solomon-mods
```

## Use

Commands: /helpers · /team.
It opens as a tab beside the chat.
Turn it, or any part of it, on or off from the Mods tab (`/mods`).

## Parts you can switch off

- `cards`: A card per helper agent
- `todos`: Saved to-do list
- `dock`: Team size and helper model for the next request
- `autoopen`: Open the tab by itself when helpers start
