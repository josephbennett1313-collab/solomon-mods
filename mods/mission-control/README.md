# Mission Control

A goal bar that tracks the real task list, /goal, and an All Tasks view across every open chat.

Part of [Solomon Mods](https://github.com/josephbennett1313-collab/solomon-mods), a free set of Claude Code mods by Joseph Bennett.

## Install

```
/plugin marketplace add josephbennett1313-collab/solomon-mods
/plugin install mission-control@solomon-mods
```

## Use

Commands: /mission · /alltasks (and Claude Code's /goal).
It opens as a tab beside the chat.
Turn it, or any part of it, on or off from the Mods tab (`/mods`).

## Parts you can switch off

- `taskbar`: Task bar above the prompt
- `goal`: Goal meter for /goal
- `activity`: Activity feed in plain words
- `smart-words`: Smarter activity wording (uses a small model call)
- `autoopen`: Open the pane when helpers start
- `open-at-start`: Open the pane when a chat starts
- `nudge`: Remind Claude to keep a task list
- `worker-steps`: Let helpers report their steps
