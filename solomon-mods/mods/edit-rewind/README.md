# Edit Rewind

Step through a turn's edits, undo a turn, and restore from a snapshot timeline.

Part of [Solomon Mods](https://github.com/josephbennett1313-collab/solomon-mods), a free set of Claude Code mods by Joseph Bennett.

## Install

```
/plugin marketplace add josephbennett1313-collab/solomon-mods
/plugin install edit-rewind@solomon-mods
```

## Use

Commands: /rewind-edits · /tm.
It opens as a tab beside the chat.
Turn it, or any part of it, on or off from the Mods tab (`/mods`).

## Parts you can switch off

- `hint`: Show the rewind hint above the prompt
- `status`: Show edit count in the status line
