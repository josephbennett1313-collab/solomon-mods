# Prompt Forge

Turns a long brain dump into a clear brief in Anthropic's recommended shape, asks the questions that matter first, and queues next prompts with /after.

Part of [Solomon Mods](https://github.com/josephbennett1313-collab/solomon-mods), a free set of Claude Code mods by Joseph Bennett.

## Install

```
/plugin marketplace add josephbennett1313-collab/solomon-mods
/plugin install prompt-forge@solomon-mods
```

## Use

Commands: /forge · /after · /shape · /coach.
It shows above the prompt or acts in the background.
Turn it, or any part of it, on or off from the Mods tab (`/mods`).

## Parts you can switch off

- `shape`: Catch long brain dumps, ask what matters, and offer an "Act as" brief
- `coach`: Suggest a sharper version of short, vague prompts
- `after`: /after queue: send prompts when Claude finishes
