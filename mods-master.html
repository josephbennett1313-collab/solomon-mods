1. Your Solomon Suite (11 mods, on)

What it does / what it piggybacks on
  • Mission Control – task bar and /goal meter above the prompt, a live card per helper agent, plain-English activity feed with time saved. Built from: Helper Desk (Ben AI), Savvy Progress, Agent Narrator, Goal Meter idea (Nate Herk).
  • Session Keeper – cache clock with Keep Warm, and one-click Handoff that moves a long chat into a fresh one. Built from: Cache Clock + Handoff (Ben AI).
  • Prompt Forge – turns a long brain dump into a clear brief, suggests a sharper version of a vague prompt, /forge upgrades any prompt. You always choose. Built from: Brain Dump (Ben AI), Prompt Coach.
  • Rule Keeper – turns your corrections into rules (this chat, every chat, or your vault) and pins notes and to-dos above the prompt. Built from: Reflect (Ben AI), Pin Memo.
  • Chat Ledger – what this chat used (to-dos, connectors, files, skills) and Today’s Report of tasks, hours saved and dollar value. Built from: Chat Inventory (Ben AI), Today’s Report idea (Tristen O’Brien).
  • Mod Switchboard – /mods turns each mod, or one part of it, on or off. Built from: Switchboard (Ben AI).
  • Edit Rewind – step through last turn’s edits, undo a turn, full snapshot timeline to restore or branch. Built from: Time Machine, Replay Theater (Anthropic sample).
  • Privacy Shield – greys out names, emails, phones and amounts while you share your screen; keeps keys out of what Claude reads; blocks .env and SSH key files. Built from: Screen-Share Mode (Ben AI), Secret Redactor.
  • Assumption Radar – lists decisions Claude made without asking and the assumptions it made, so you mark each right or wrong. Built from: Critical Decisions, Assumption Check idea (AI Labs).
  • Auto Model – Sonnet for normal work, your chosen model for deep work; only switches at chat start or cold cache. Idea: Tristen O’Brien.
  • Design Picker – /styles shows each design style as a preview before you pick. Idea: AI Labs; styles from UI UX Pro Max.
Your settings show Mission Control and Chat Ledger panels set to hidden – a sign they felt noisy. The UI section below addresses that.

6. Rebuild plan – Solomon Suite v2 on GitHub

Recommendation: one private GitHub repo, solomon-mods, set up as a mod marketplace. Both Macs install from it, so updates reach both and nothing depends on a local folder.

Result: 16 of your own mods + Codex replace all 24 installed.
  • Keep (9): Mission Control, Chat Ledger, Mod Switchboard, Edit Rewind, Privacy Shield, Assumption Radar, Auto Model, Design Picker, plus Codex as is
  • Upgrade (3): Session Keeper v2 (+ Token Optimizer bar, Token Weather), Prompt Forge v2 (+ After queue), Rule Keeper v2 (+ remcycle memory)
  • New (5): Limit Guard, Command Guard, My Tasks, Voice Guard, Site Check
Order:
  1. Copy the 11 Solomon Suite mods from the saved copies on the Mac mini into the new repo. (Or from ~/Projects/claude-mods on the MacBook if it is newer.)
  2. Build the 3 upgrades – they touch what you see every session.
  3. Build the 5 new mods, rewritten in your own code (not copied), same Solomon look.
  4. Test each for a week, then uninstall the downloaded original.
Trade-off: owning everything means you also own the fixes. When Anthropic changes the mod system, your mods break until Claude repairs them; downloaded ones get fixed by their authors.

7. What a new session should look like – suggestions

Idea: one Start Deck above the prompt that shows only what matters when a chat opens, then shrinks to a single line after your first message.

Row 1 – always on (one line)
Solomon · Mac mini · Sonnet · Quality A · Context 3% · Week 38% · 21 mods on [Mods]

Row 2 – Pick up where you left off (only if something is waiting)
Last handoff: “Fire rebuild invoice” [Resume] · 2 tasks waiting on you [Open] · 1 queued prompt · 3 memory rulings

Row 3 – Quick starts
[Captivia] [Blue Ocean] [Ophir] [Real estate] [Solomon build] – each loads that project’s folder, rules and connectors.

Rules for the deck
  • Quiet by default: panels like Mission Control and Chat Ledger open only when helpers start or you click.
  • One alert at a time, colour-coded: orange = needs you, grey = info.
  • Crab orange accent, big tap targets, readable on your phone.
  • Privacy Shield button on the deck for one-tap screen-share mode.
  • Every number on the deck is clickable and explains itself in plain English.
